# Cybersecurity & Software Engineering Portfolio

Personal portfolio of **Mickaël Van Craenenbroeck** — Tech Lead & Cybersecurity Analyst (`DevSecOps & Infrastructure • Tech Coach`).

## Overview

- **Bilingual Static Architecture (EN / FR):** Zero-dependency static HTML5 & Tailwind CSS architecture ready for GitHub Pages deployment.
- **Navigation Structure:**
  - `~/portfolio` (`index.html`): Overview & quick navigation tree.
  - `~/about` (`about.html`): Analyst profile, technical proficiencies, professional experience, and certifications.
  - `~/projects` (`projects.html`): Real-world hardware/software security deployments and software engineering case studies:
    - **Project Sentinel** (`sentinel.html`): Autonomous Raspberry Pi 3A+ inline network drop box & IDS/IPS probe.
    - **Project Marauder** (`marauder.html`): Standalone ESP32 hardware Wi-Fi auditing tool in C/C++.
    - **Project Vova** (`vova.html`): Pwnagotchi companion dashboard, custom binary PCAP/EAPOL parser, and 3D-printed Raspberry Pi 3A+ hardware integration.
    - **Network Port Scanner & Vuln Analyzer** (`scanner.html`): Multi-threaded Python/Scapy SYN scanner with asynchronous NIST NVD CVE enrichment.
    - **Host Intrusion Detection System (HIDS)** (`hids.html`): Zero-dependency POSIX/Bash & Python endpoint integrity and process auditing daemon.
    - **Trek Organizer** (`trek.html`): Full-stack outdoor expedition management platform (Laravel / SQL) and off-grid ESP32 LoRa mesh hardware tags.
  - `~/contact.asc` (`contact.html`): Direct communication channels and public PGP key.
