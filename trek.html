Trek Organizer: Autonomous Outdoor Management & LoRa Mesh Ecosystem

A comprehensive web application designed for autonomous mountain trekking, climbing, cycling, and trail running management. Built to demonstrate robust backend architecture, secure database interactions, full-stack deployment capabilities, and off-grid ESP32 LoRa mesh hardware integration.

Project Concept & Architectural Evolution

Preparing autonomous expeditions in mountain environments—whether trekking, climbing, cycling, or trail running—requires coordinating multiple critical variables: equipment weight, GPX routing, localized weather windows, group logistics, and off-grid safety. Trek Organizer centralizes all of these workflows into a unified full-stack application.

Tech Migration Disclaimer: This project is currently undergoing a major architectural migration to align with modern industry standards and AI integration requirements:
  • Current Stack: Laravel 10 (Blade, Eloquent ORM, MySQL / SQLite, Laravel Breeze authentication).
  • Future Stack (In Progress): Next.js 15 (App Router), TypeScript, Tailwind CSS, and Prisma ORM to improve real-time capabilities, strict type safety, and seamless integration with AI SDKs.

Core Application Modules & Features

> 1. Gear Catalog & Modular Backpacks

The equipment engine allows users to build a granular personal gear catalog, recording each item's brand, model, weight, volume, price, place of purchase, and category (sleep, eat, clothes, hygiene, equipment) with instant search and filtering.

From this inventory, trekkers can compose multiple specialized backpack configurations (e.g., long GR trek, winter weekend, climbing outing, cycling trip). Each backpack automatically computes total weight and volume in real time, and smart filters highlight the pack best suited to the planned outing duration and shelter type.

> 2. Itineraries & Interactive GPX Mapping

Users can create detailed itineraries (name, dates, location, cover image, description), attach and manage personal GPX files, and visualize tracks on an interactive fullscreen map with layer toggles. A shared community library also allows hikers to discover and download GPX routes uploaded by other members.

> 3. Weather Telemetry & Geocoding

Integrating the Google Maps Geocoding API and Open-Meteo API, the weather module enables trekkers to bookmark favorite high-altitude locations and monitor reliable real-time and multi-day meteorological forecasts.

> 4. Group Budgets, Community Forum & Outdoor News

To streamline group expeditions, Trek Organizer includes a multi-participant Budget & Expense Splitter (tracking transactions by amount, type, user, and outing), a collaborative Forum for trip preparation, and an automated Outdoor News Feed powered by SimplePie RSS aggregation.

Hardware Integration: ESP32 LoRa Mesh Network

Trek Organizer extends beyond the web with custom-built hardware tags based on ESP32 microcontrollers and the LoRa (Long Range) radio protocol. These tags are specifically engineered for cellular "white zones", establishing an autonomous local mesh network between trekkers to ensure safety and connectivity.

  • Offline Mesh Connectivity: Enables peer-to-peer chat and GPS coordinate sharing between devices without relying on telecom infrastructure.
  • Decentralized SOS System: Broadcasts emergency distress beacons across nearby mesh nodes.
  • Data Mule Architecture: Collects environmental telemetry offline, buffers packets in non-volatile memory, and synchronizes with the main Trek Organizer platform via the smartphone gateway once Wi-Fi/4G connectivity is restored.

AI & Data Science Vision

The long-term roadmap evolves Trek Organizer from an expedition management platform into an intelligent field assistant and citizen-science data provider:

  • Edge AI (TinyML): Running lightweight neural networks directly on the ESP32 microcontroller for autonomous fall detection and predictive battery power management.
  • Citizen Science & Environmental Telemetry: Turning trekkers into mobile sensor stations for high-resolution micro-climate mapping, anomaly detection (Isolation Forests for early-stage wildfire detection), and on-device bioacoustic bird species classification over low-bandwidth LoRa links.
  • Predictive Analytics: Personalized ETA engine learning from historical user pace across varying elevation gradients and terrain types.
