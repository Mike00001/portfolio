# The Objective

The Sentinel project was born from the need to effectively monitor a home network and learn defense-in-depth mechanisms. The goal was to build a network probe capable of analyzing traffic in real-time, identifying malicious packets, and blocking active threats, all on an affordable and low-power device (Raspberry Pi).

# Technical Architecture

  • Hardware: Raspberry Pi 4 (4GB RAM) connected to the mirror port (SPAN) of a managed switch.
  • Analysis Engine: Suricata configured in IDS mode for detection, and IPS via firewall rules (iptables/nftables) for blocking.
  • Visualization: ELK Stack (Elasticsearch, Logstash, Kibana) or Prometheus/Grafana to display alerts via comprehensive dashboards.

# Challenges Faced

The main difficulty lay in optimizing Suricata's performance on the Raspberry Pi's ARM architecture. Deep Packet Inspection required:

  • Adjusting Suricata's multi-threading.
  • Disabling less relevant signatures to free up RAM.
  • Externalizing log persistence (Elasticsearch) to a separate server to relieve the Pi's SD card.

# Results and Learnings

Sentinel is now my primary tool for capturing and understanding common attack patterns. I have deeply improved my skills in TCP/IP packet analysis, writing Suricata rules (Snort syntax), and managing false positives.
