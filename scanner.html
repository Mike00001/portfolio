Project Concept & Comparison with Standard Scanners

In security auditing, mapping the target's attack surface is the critical first step. Standard utilities like Nmap are powerful, but they operate as heavy, compiled binaries that are difficult to programmatically script inline, customize for specific output formats, or interface directly with real-time web databases.

Network Port Scanner & Vuln Analyzer is a custom, scriptable network reconnaissance tool written in Python. It blends raw socket network mapping with real-time asynchronous vulnerability enrichment:

  • Dual Scanning Models: Supports TCP Connect sockets for standard system compliance and raw Scapy packet injection for stealth SYN scanning.
  • Integrated Threat Database Querying: Grabs service banners and matches them asynchronously against the NIST National Vulnerability Database (NVD) in a single workflow.
  • Built-In Evasion Controls: Features serialization limits and jitter delays to bypass network Intrusion Detection Systems (IDS).

Networking Performance & Protocol Adaptations

Running concurrent scans across large subnets requires optimizing network I/O, socket lifecycle parameters, and packet rates:

> 1. Concurrent CPU & Thread Pool Management

To scan large networks without saturating the host CPU or exhausting memory, the tool uses a ThreadPoolExecutor. It splits subnets into chunks and caps worker threads.

> 2. Socket Optimization and Reusable Addresses

Scanning thousands of ports in a short window leaves sockets in a TIME_WAIT state. The engine configures SO_REUSEADDR and implements aggressive timeouts.

> 3. Dynamic Rate Limiting & Evasion Jitter

To avoid triggering IDS firewalls, the script implements threading.Lock to enforce global rate limits and randomizes port search orders with random delays (jitter).

> 4. Raw Packet Construction (Scapy L3 Injection)

For stealth scans, the scanner bypasses the OS transport layer and creates custom IP/TCP headers directly in-memory using Scapy, sending raw SYN packets without finishing the handshake.

CLI Command Reference

python3 main.py --target 192.168.1.0/24 --mode syn — Runs stealth SYN scan across local subnet.

python3 main.py --target 10.0.2.15 --ports 22,80,443 --enrich — Scans ports & queries NIST API.

python3 main.py --help — Displays export options (HTML, JSON, CSV, XML).
